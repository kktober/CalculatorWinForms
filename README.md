# Калькулятор — Windows Forms (C#)

Учебный проект для кейс-задачи № 3. Приложение реализовано на C# с использованием Windows Forms и .NET 8.

## Возможности
- Ввод цифр 0–9 и десятичной точки.
- Сложение, вычитание, умножение и деление.
- Последовательные вычисления с сохранением промежуточного результата.
- Кнопки `=` и `C`, смена знака `±` и удаление последнего символа `⌫`.
- Проверка деления на ноль и некорректных/переполненных результатов.
- Сохранение и загрузка истории вычислений в JSON.
- Переключение светлой и тёмной цветовой темы.

## Требования
- Windows 10/11.
- Visual Studio 2022 с workload **.NET desktop development**.
- .NET 8 SDK.

## Запуск в Visual Studio
1. Распакуйте архив проекта.
2. Откройте `CalculatorWinForms.csproj` в Visual Studio 2022.
3. Убедитесь, что установлен .NET 8 SDK и компонент «Разработка классических приложений .NET».
4. Нажмите `F5` или выберите **Debug → Start Debugging**.

## Проверка
Проверьте, например:
- `12 + 8 =` → `20`.
- `20 − 5 =` → `15`.
- `7 × 6 =` → `42`.
- `10 ÷ 4 =` → `2.5`.
- `8 ÷ 0 =` → сообщение об ошибке.
- `2 + 3 × 4 =` → последовательное выполнение слева направо: `20`.

История сохраняется в JSON через кнопку «Сохранить историю» и загружается через «Загрузить историю».
